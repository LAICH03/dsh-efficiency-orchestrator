# dsh-efficiency-orchestrator

One plugin, two kinds of leverage: it replaces DSH's `read` / `glob` / `grep` with `ops_*` aliases and orchestrates batch tool calls, reasoning-loop breaking, and session budgets to save tokens and steps.
